## Skills del Proyecto
Todas las skills del proyecto están centralizadas exclusivamente en `.agents/skills/`.
Antes de realizar tareas o modificar código sobre contratos Soroban, frontend/dApp Stellar, base de datos/Supabase, reglas de forja/estándares, pagos o pruebas ZK, lee y sigue las directivas de `.agents/skills/<skill-name>/SKILL.md`.
